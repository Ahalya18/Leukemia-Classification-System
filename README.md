# Leukemia Classification System

## Overview
An AI-powered leukemia detection system developed using Deep Learning and FastAPI to classify blood smear images and assist in early diagnosis.

## Technologies Used
- Python
- FastAPI
- HTML
- CSS
- JavaScript
- SQLite
- OpenCV
- Deep Learning
- Grad-CAM

## Features
- Blood smear image classification
- Explainable AI visualization using Grad-CAM
- Patient history tracking
- Real-time prediction interface
- Secure login system

## Project Structure
- main.py – Application entry point
- inference.py – Prediction pipeline
- grad_cam.py – Explainability module
- database.py – Database operations
- models.py – Data models

## Future Enhancements
- Cloud deployment
- Multi-class leukemia classification
- Doctor dashboard integration
